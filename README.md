# E-Commerce Analytics Project

## Project Overview

This is an end-to-end E-Commerce Data Analytics project developed using Excel, MySQL, Python and Power BI.

The project analyzes e-commerce business data to understand sales performance, profitability, customer behavior, product performance and product returns.

---

## Tools and Technologies

- Microsoft Excel
- MySQL
- SQL
- Python
- Pandas
- Power BI
- DAX
- Power Query

## Dataset

The project uses the following datasets:

- Customers
- Orders
- Products
- Returns

## Excel

Excel was used for initial data cleaning and preparation of the datasets.

Data cleaning operations included working with functions such as:

- TRIM
- XLOOKUP
- VLOOKUP

---

## SQL Analysis

The cleaned datasets were imported into MySQL for database analysis.

The SQL analysis included:

- Creating database tables
- Loading datasets
- Data analysis queries
- Joins
- Aggregations
- CTEs
- Window Functions
- RFM Analysis

---

## Python Analysis

Python was used for further data analysis and exploration of the e-commerce dataset.

---

## Power BI Dashboard

An interactive 5-page Power BI dashboard was created.

### 1. Executive Overview

Provides an overall view of business performance using key performance indicators.

### 2. Sales Analysis

Analyzes sales trends, revenue by category and payment methods.

### 3. Customer Analysis

Analyzes customers, regions and customer revenue performance.

### 4. Product Analysis

Analyzes product performance, category revenue, profit and quantity sold.

### 5. Returns Analysis

Analyzes returned orders, return rate, return reasons and return trends.

---

## Key KPIs

The dashboard includes the following KPIs:

- Total Revenue
- Total Profit
- Profit Margin
- Total Orders
- Total Quantity
- Average Order Value
- Total Customers
- Returned Orders
- Return Rate
